30日クイックスタート（最初の30日だけ）

全部を一度に理解しなくていい。この30日は「1記事を公開して、導線を1本作る」だけ。

Day 1-2：決める　[所要: 1〜2時間]

やること:

  • ジャンルを1個決める（1ヶ月やってみる前提でOK）。プロンプトP1〜P5。
  • 作業枠を予定表に入れる（平日30〜60分／休日2〜3時間）。

詰まりやすいポイント: 「ジャンルが決められない」→ P1を使い、候補10個出してから迷う時間を10分に絞る。

完了チェック: ジャンルを1行で書けた。作業時間が予定表に入った。

Day 3-5：仕込む　[所要: 2〜3時間]

やること:

  • 主要ASPに登録、案件を本命1＋代替1。プロンプトP16・P17。
  • 狙うキーワードを1個決める（1記事=1KW）。プロンプトP6〜P10。

詰まりやすいポイント: 「ASP審査が通らない」→ 記事0本でも登録できるASPから始める（a8.net等）。

詰まりやすいポイント: 「KWが決まらない」→ P6で20個出してからP7で5個に絞る手順を守る。

完了チェック: ASP登録完了。紹介できる案件を1つ選んだ。KWを1個決めた。

Day 6-12：1本書く　[所要: 3〜5時間 / 分割OK]

やること:

  • 構成→執筆→公開（70%で出す）。プロンプトP21・P26・P28。
  • 公開できたらDay目標達成。完璧を狙わない。

詰まりやすいポイント: 「1本書けない・長すぎる」→ 見出し5本・各見出し200字で計1,000字を目標にする。

詰まりやすいポイント: 「公開ボタンが押せない」→ 「あとで修正できる」と声に出してから押す。

完了チェック: 公開URLが存在する。

Day 13-20：流す＋次の1本　[所要: 各日30〜60分]

やること:

  • 記事をX/Threads/ショートで流す（プロンプトP31〜P40）。
  • 2本目を同じ型で書く。

詰まりやすいポイント: 「投稿の反応がない」→ まだ土台期。反応より「出した数」をカウントする。

詰まりやすいポイント: 「2本目が遅い」→ P21の構成だけを先に出してから書き始める。

完了チェック: 流し投稿を3本以上出した。2本目が下書きまで進んでいる。

Day 21-27：導線を1本　[所要: 2〜4時間]

やること:

  • 無料特典＋LINE登録の入口を1つ作る。プロンプトP61〜P63・モジュールM9。

詰まりやすいポイント: 「特典のネタがない」→ P61で候補を10個出す。自分が「もらったら嬉しい」1個を選ぶだけ。

詰まりやすいポイント: 「LINEの設定が複雑」→ プロラインフリーのテンプレ設置から始める（M8参照）。

完了チェック: 無料特典の名前と目次が決まった。LINE登録ページへのリンクが1本ある。

Day 28-30：見て、決める　[所要: 1時間]

やること:

  • 一番見られた記事を1本だけ特定（プロンプトP71）。
  • 次の30日に持ち越す「仮説1つ」をメモ。

詰まりやすいポイント: 「数値の見方がわからない」→ 「PVが多い記事=読まれた」だけ確認。複雑な分析はW9以降。

完了チェック: 「よく見られた記事名」と「次30日の仮説1行」をメモした。

Make自動化版（GSheets → Make → Buffer）

事前準備：

  • Googleスプレッドシートを用意（列：date / text / platform / status）
  • Makeアカウント作成（https://make.com）
  • Buffer APIトークン取得（Buffer管理画面→Settings→Integrations→API）

Makeシナリオの流れ:

トリガー：Google Sheets - Watch Rows
  └── 新しい行を検知（status="pending" の行）
        │
        ▼
アクション：HTTP - Make a Request
  └── Buffer Create Post API を呼ぶ
      ├── method: POST
      ├── URL: https://api.bufferapp.com/1/updates/create.json
      └── body: text / scheduled_at / profile_ids
        │
        ▼
アクション：Google Sheets - Update Row
  └── status を "sent" に変更

主な設定値:

  • スケジュール間隔：15分ごと（Makeの最小間隔）
  • scheduled_at：シートの date 列を Unix timestamp に変換
  • profile_ids：Buffer管理画面から取得する自分のアカウントID

Makeが初めての場合は完全無料版で月10本を安定運用してから切り替える。

日目目的送る内容タイミングの理由

3〜4日後アンケート「今あなたはどの段階？」4問行動が起きているかチェック
5〜6日後教育つまずきポイントの先回り情報アンケート回答を見て出し分け
7日後教育+信頼体験談・Before/After1本1週間の節目。感情が動きやすい
10〜14日後オファー案内有料商品・相談会の案内信頼が積み上がったタイミング
21日後リマインド「まだ迷っている人向け」フォロー購入を保留した人の再呼び起こし

開封率の目安：登録直後70% → 3日後50% → 14日後25%
